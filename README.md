# FableMacro

이미지 검색 · OCR · 조건 분기 기반 **이미지 매크로** Android 앱.
다른 앱 위에서 **오버레이(플로팅 버블 + 패널)** 로 동작하며, 스크립트를 만들어 자동 플레이할 수 있습니다.

> 본인 기기에서 본인이 사용하는 앱의 반복 작업 자동화 용도로 사용하세요.
> 게임/서비스 약관에 따라 매크로 사용이 제한될 수 있습니다.

## 기능

- **이미지 검색 후 클릭** — 화면 영역을 드래그로 캡처해 템플릿으로 저장, 화면에서 찾아 클릭 (임계값 조절 가능)
- **텍스트 검색 후 클릭 (OCR)** — ML Kit 한국어 OCR로 화면에서 텍스트를 찾아 클릭
- **조건 분기** — 각 스텝마다 성공/실패 시 이동할 스텝 지정 (다음 / 중지 / n번 스텝 점프)
- **재시도 루프** — 검색 액션은 무한(∞) 또는 n회 재시도 + 재시도 간격 설정
- **액션 이름 지정** — 각 스텝에 원하는 이름을 붙여 리스트에서 바로 구분 (⚙ → 액션 이름)
- **좌표 위치 확인 (◎)** — 탭/스와이프/경로/영역이 화면 어디에 설정됐는지 약 1.8초간 표시
- **자동 업데이트** — 실행 시 GitHub 릴리스에서 새 버전을 확인하고 앱 안에서 바로 설치
- **액션 종류**: 탭 · 스와이프 · 경로 · 딜레이 · 이미지 검색 · 텍스트 검색 · OCR 복사 · 텍스트 붙여넣기 · 앱 실행 · 뒤로가기 · 홈 · 최근 앱 · 랜덤 탭
- **스크립트 저장/불러오기** — JSON으로 저장, 여러 스크립트 관리
- **링크로 매크로 받기** — 받은 링크 하나로 매크로를 통째로 등록 (템플릿 이미지까지 포함)
- **웹 카탈로그** — 브라우저에서 매크로 목록을 보고 단계를 고쳐 나만의 링크 생성

## 설치 / 업데이트

### 최초 설치
[Releases](https://github.com/Hwanje/fablemacro/releases/latest)에서 최신 `FableMacro-x.y.z.apk` 다운로드 후 설치.

### 이후 업데이트
앱을 실행하면 자동으로 새 버전을 확인합니다. 새 버전이 있으면 안내 창에서
**지금 업데이트**를 누르면 다운로드 후 설치 화면이 바로 열립니다.
(수동 확인은 메인 화면의 **업데이트 확인** 버튼)

최초 1회 "알 수 없는 앱 설치" 권한 허용이 필요합니다.

## 사용 방법

1. APK 설치 후 앱 실행
2. **다른 앱 위에 표시** 권한 허용
3. **접근성 서비스** 켜기 (탭/스와이프 제스처 실행에 필요)
4. **화면 캡처 승인 후 시작** → 플로팅 버블 등장
5. 자동화할 앱으로 이동 → 버블 탭 → 패널에서 액션 추가
   - 이미지 검색: 찾을 버튼/아이콘 영역을 드래그로 지정하면 자동 캡처됨
   - ⚙ : 액션 이름 / 재시도 횟수(0 = ∞) / 성공·실패 분기 / 임계값 설정
   - ◎ : 설정된 좌표·영역이 화면 어디인지 잠시 표시
   - ▷ : 해당 스텝만 단독 실행
6. ▶ 실행 — 실행 중 버블(■)을 탭하면 중지

## 온라인 매크로 (링크 · 웹 카탈로그)

웹사이트: **https://hwanje.github.io/fablemacro/**

### 링크로 매크로 가져오기
매크로 링크는 `fablemacro://import?…` 형태이며 두 종류가 있습니다.

| 형태 | 뜻 |
|---|---|
| `fablemacro://import?m=<id>` | 카탈로그에 올라간 매크로를 받아옴 (짧음) |
| `fablemacro://import?p=<데이터>` | 매크로가 링크 안에 통째로 담김 (카탈로그에 없어도 됨) |

받는 방법은 세 가지입니다.
1. **폰에서 링크 탭** → 미리보기 확인 후 저장
2. **오버레이 📚 → 링크로 가져오기** → 링크 붙여넣기 (클립보드 자동 인식)
3. 위 칸에 **매크로 JSON 본문**이나 `https://…/xxx.json` 주소를 그대로 붙여넣어도 됩니다

내 매크로를 링크로 만들려면 📚 → 매크로 선택 → 더보기 → **공유 링크 만들기**.

### 웹 카탈로그에서 보고 고치기
- 매크로 목록을 카드로 보고 이름·설명·태그로 검색
- 매크로를 열면 단계를 확인하고 **직접 편집** (단계 추가/삭제/순서 변경, 좌표·텍스트·분기·재시도 수정)
- 순서를 바꿔도 분기(성공/실패 시 이동) 대상이 원래 단계를 계속 가리킵니다
- 고친 결과는 **앱으로 가져오기 / 링크 복사 / JSON 내려받기 / GitHub에 저장** 중 원하는 방식으로

### 카탈로그에 매크로 추가하기
`docs/macros/<id>.json` 파일을 추가하면 끝입니다. 웹 편집기의 **GitHub에 저장**이 이 파일을 만드는 화면을 열어줍니다.
푸시되면 `Rebuild macro catalog` 워크플로가 `docs/macros/index.json`을 자동으로 다시 만들어 목록에 반영합니다.

### GitHub Pages 켜기 (최초 1회)
Settings → Pages → Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/docs` 로 지정하세요.
Pages를 켜기 전에도 **링크로 가져오기는 그대로 동작합니다** — 앱은 카탈로그를 `raw.githubusercontent.com`에서 직접 읽습니다.

## 빌드

### GitHub Actions
- `main` 푸시 → **Release APK** 워크플로가 버전을 `1.0.<run_number>`로 올려 빌드하고 GitHub Release 발행
- 그 외 브랜치 푸시 → **Build APK** 워크플로가 디버그 APK를 아티팩트로 업로드

### 로컬 빌드
```bash
./gradlew assembleDebug
# 출력: app/build/outputs/apk/debug/app-debug.apk
```
Android SDK (API 35) 필요. `local.properties`에 `sdk.dir=<SDK 경로>` 지정.

## 기술 구성

| 구성 | 구현 |
|---|---|
| 제스처 실행 | AccessibilityService `dispatchGesture` |
| 화면 캡처 | MediaProjection + ImageReader |
| 이미지 매칭 | 순수 Kotlin 2단계 SAD 템플릿 매칭 (OpenCV 불필요) |
| OCR | ML Kit Text Recognition (한국어, 온디바이스) |
| 오버레이 | `TYPE_APPLICATION_OVERLAY` 플로팅 버블/패널 |
| 저장 | Gson JSON + PNG 템플릿 |
| 업데이트 | GitHub Releases API + FileProvider 설치 |

- minSdk 26 (Android 8.0) / targetSdk 35

### 서명키에 대해

자동 업데이트로 기존 앱 위에 덮어쓰기 설치가 되려면 모든 빌드가 **같은 키**로 서명되어야 하므로,
`app/signing/fablemacro.keystore`를 저장소에 포함해 CI가 항상 이 키로 서명합니다.
개인 사이드로드용 앱 기준의 선택이며, 이 키는 공개되어 있으므로 Play 스토어 배포 등
서명키가 비밀이어야 하는 용도라면 키를 새로 만들어 GitHub Secrets로 주입하도록 바꿔야 합니다.
